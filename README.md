# AWS Girls Perú

Sitio web oficial de **AWS Girls Perú**, comunidad de mujeres apasionadas por la tecnología cloud en Perú.

Más de 1,200 miembros • 44+ eventos • Lima, Perú

## Sitio web

https://dicaalba.github.io/aws-girls-peru/

## Stack

- HTML + CSS + JavaScript vanilla
- PWA (Progressive Web App) con Service Worker
- Sin frameworks ni dependencias de frontend

## Scripts

```bash
# Scraper de datos
npm run scrape
```

## Estructura

```
├── index.html       # Página principal
├── styles.css       # Estilos
├── app.js           # Lógica de la app
├── sw.js            # Service Worker
├── manifest.json    # PWA manifest
├── data.json        # Datos de eventos y miembros
└── scraper.js       # Script de scraping
```
